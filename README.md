# spires_testing

Benchmark harness, verification tests and raw results for the
[SPIRES](https://github.com/txmastin/spires) manuscript *SPIRES: An Extensible
Low-Level Framework for Liquid State Machines*. Everything needed to rerun the
measurements and regenerate the manuscript's tables from the raw data is here.

SPIRES is compared against nine reservoir-computing and spiking-network
frameworks: reservoirpy, pytorch-esn, ReservoirComputing.jl, snnTorch, norse,
rockpool, Brian2, NEST and ANNarchy.

## Layout

```
src/bench/      runners (one per framework), orchestrator, tuner, verification,
                table generation, plots
config/         tuned.json            per (framework, task) operating points, revision
                tuned_submitted.json  as used for the submitted manuscript
data/           NARMA-10 and Mackey-Glass series, generated by gen_data.py
results/
  revision/     the run behind every timing and accuracy in the revised manuscript
  submitted/    the run behind the submitted manuscript
  *.json        verification, deployability, plasticity and topology results
Makefile        builds the C runners against a SPIRES checkout
run_revision_overnight.sh   the full revision run (about 6 h)
```

Each line of a results `.jsonl` file is one measurement: `framework`, `n`
(reservoir size), `task`, `rep`, `threads`, wall time (`t_harvest`, `t_fit`)
and CPU time (`cpu_harvest`, `cpu_fit`) of the measured region, accuracy
(`nrmse` is the test score; `nrmse_train`, `nrmse_val` and `split` in the
revision run), the CPU `governor`, and `status`.

## Environment

The reported results were measured on an Intel Core i7-10510U (4 cores,
8 hardware threads), Linux 6.18, CPU governor `performance`, with:

- SPIRES at commit `97e068b`, built with clang 22.1.8 and OpenBLAS
- Python 3.14.6 with the packages in `requirements.txt`
- NEST 3.10.0 (`nest-simulator`), installed following the NEST documentation
- Julia 1.12.6 with ReservoirComputing.jl 0.12.29

clang is required for the C runners: `libspires.a` carries LLVM OpenMP symbols
and will not link against libgomp.

Paths default to the authors' layout and can be overridden:

| Variable | Meaning | Default |
|---|---|---|
| `SPIRES_DIR` | SPIRES checkout, built with `make` | `~/programming/projects/spiking-reservoir/spires` |
| `BENCH_VENV` | Python virtual environment | `~/.pyvenv` |
| `JULIA_DEPOT_PATH` | Julia depot | `~/.julia` |
| `TABLES_DIR` | where `make_tables.py` writes | `tables/` |

ANNarchy needs `VIRTUAL_ENV` to point at the venv so that its CMake step finds
the right interpreter; the orchestrator sets it.

## Building

```sh
make SPIRES_DIR=/path/to/spires
python -m venv ~/.pyvenv && ~/.pyvenv/bin/pip install -r requirements.txt
julia -e 'using Pkg; Pkg.add(name="ReservoirComputing", version="0.12.29")'
```

## Regenerating the tables from the included results

```sh
python src/bench/make_tables.py --revision   # revised manuscript, from results/revision/
python src/bench/make_tables.py              # submitted manuscript, from results/submitted/
```

## Rerunning the measurements

Timings depend on machine load. Run on an otherwise idle machine with the
`performance` governor; `check_clean.py` flags any one-thread cell whose CPU
time falls short of its wall time.

```sh
python src/bench/gen_data.py                  # NARMA-10 and Mackey-Glass (already in data/)
./run_revision_overnight.sh                   # ridge selection, 1/2/4/8-thread sweeps, Brian2 runtime target
```

A single cell, or a quick check that every runner works:

```sh
BENCH_THREADS=1 python src/bench/orchestrate.py --sizes 100 --reps 1 \
    --tasks narma10 --out results/smoke.jsonl
```

`BENCH_THREADS` sets the thread budget for every framework (environment and,
where a framework sets its own, its API). Brian2 runs under its
`cpp_standalone` device by default; `BRIAN2_MODE=runtime` selects the runtime
target.

## Verification

```sh
python src/bench/verify_exact.py           # fractional neurons against the exact Mittag-Leffler solution
python src/bench/collect_verification.py   # integer- and fractional-order dynamics, configuration conformance
python src/bench/verify_topology.py        # network topology generators
python src/bench/collect_stdp.py           # plasticity windows and homeostasis
```

The C programs `src/bench/test_*.c` are unit tests of the plasticity rules,
random-number isolation and sign conventions; `make` builds them.

## Datasets

The classification tasks use third-party corpora that are not redistributed
here. Place them under `data/` and run the preparation scripts:

- Spiking Heidelberg Digits (SHD), Zenke lab: `data/shd/shd_{train,test}.h5`,
  then `python src/bench/prep_shd.py`
- Free Spoken Digit Dataset (FSDD),
  <https://github.com/Jakobovski/free-spoken-digit-dataset>:
  `data/fsdd/recordings/`, then `python src/bench/prep_fsdd.py`
